---
title: "Incidents"
description: "Communicate outages to your users"
---

Incidents track service disruptions and keep your users informed through their lifecycle.

## Lifecycle

1. **Investigating** — Issue detected, looking into it
2. **Identified** — Root cause found
3. **Monitoring** — Fix deployed, watching for stability
4. **Resolved** — Issue confirmed fixed

## Impact levels

| Level | Description |
|-------|-------------|
| `none` | Informational, no user impact |
| `minor` | Minor degradation |
| `major` | Significant impact |
| `critical` | Complete outage |

## Updates

Post updates to keep users informed as the situation evolves. Each update includes a status and message. Subscribers receive notifications for each update.

## Notifications

When you create or update an incident, confirmed subscribers are automatically notified via email.
