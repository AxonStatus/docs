---
title: "Quickstart"
description: "Get your status page running in 5 minutes"
---

## 1. Create your account

Sign up at [axonstatus.com](https://axonstatus.com) and create your organization.

## 2. Create a status page

After signing in, you'll be prompted to create your first status page. Choose a name and slug (e.g., `acme` for `acme.axonstatus.com`).

## 3. Add components

Components represent the services you want to track. Go to **Status Pages > Components** and add your services:

- API Server
- Web Application
- Database
- CDN

## 4. Get your API key

Go to **Settings > API Keys** and create a new key. You'll use this to interact with the API.

```bash
export AXONSTATUS_API_KEY="axon_sk_your_key_here"
```

## 5. Create your first incident

<CodeGroup>
```bash curl
curl -X POST https://api.axonstatus.com/api/v1/incidents \
  -H "Authorization: Bearer $AXONSTATUS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "API latency issues",
    "status": "investigating",
    "impact": "minor",
    "message": "We are investigating increased API response times."
  }'
```
</CodeGroup>

## 6. Embed your status

Add a status badge to your website:

```html
<script src="https://your-slug.axonstatus.com/widget/badge.js" async></script>
```

That's it! Your status page is live and your users can subscribe to updates.
