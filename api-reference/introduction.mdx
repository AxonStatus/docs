---

The AxonStatus API is organized around REST. It accepts JSON-encoded request bodies, returns JSON responses, and uses standard HTTP methods and status codes.

## Base URL

```
https://api.axonstatus.com/api/v1
```

## Authentication

Include your API key in the `Authorization` header:

```bash
Authorization: Bearer axon_sk_your_key_here
```

<Info>
Public endpoints (status overview, widget, badge, subscribe) don't require authentication.
</Info>

## Response format

All responses follow this structure:

```json
{
  "success": true,
  "data": { ... }
}
```

Error responses:

```json
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "Resource not found"
  }
}
```
