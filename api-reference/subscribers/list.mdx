---
title: "List Subscribers"
description: "Get all subscribers"
---

```
GET /api/v1/subscribers
```

| Query param | Type | Description |
|-------------|------|-------------|
| `statusPageId` | string | Filter by status page |
| `confirmed` | boolean | Filter by confirmation status |
